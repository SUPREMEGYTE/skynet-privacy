SKYNET

Privacy Policy

Effective date: 11 November 2026

SKYNET is a Windows web browser published by Patrick Grant. This policy describes information the browser stores on your device, information sent to websites and services you choose to use, and how you can control that information. The privacy practices of those third parties are governed by their own policies.

Information stored on your device

SKYNET stores browser settings, bookmarks, browsing history, download records, tab and session recovery data, profile metadata, and website data such as cookies and cache locally. These files are generally kept under %LocalAppData%\SKYNET and %LocalAppData%\SCYxNETProfiles. Website data is managed by the Microsoft Edge WebView2 runtime.

Session recovery includes non-private HTTP and HTTPS tab addresses. Private tabs are excluded from the saved session list and use temporary profiles that the browser removes when their tracked private windows close.

Diagnostic logs are stored locally under %LocalAppData%\SCYxNET\Logs. Entries can contain error messages, stack traces, timestamps, local file paths, and diagnostic context such as a URL. Logs rotate and are pruned by the application; they are not automatically uploaded.

Optional voice assistant

The voice assistant is off until you enable it with the microphone control. If enabled in settings, it starts listening again when the browser next opens. While enabled, speech is processed locally with Windows System.Speech. SKYNET does not record or upload microphone audio. Windows microphone privacy settings can deny access.

When a voice command asks the browser to search or open a website, the resulting search text or request is sent to the selected search provider or website, as it would be if entered in the address bar. A voice translation command opens Google Translate and sends the current page address to Google only when you invoke that command.

If assistant memory is enabled, recognized command text, the action taken, and a timestamp are stored locally in %LocalAppData%\SCYxNET\SkynetMemory.json, limited to the latest 200 interactions. You can disable this setting or erase the stored memory. This information is not uploaded by the app.

Network activity and IP addresses

When you visit a website, SKYNET sends the requests needed to load it. The destination website receives your IP address, the requested address, and standard browser request information. The selected search provider receives search queries and, when requested, search suggestions. This is necessary to provide browsing and search.

The Microsoft Edge WebView2 runtime may make Microsoft platform requests for runtime updates, security and reputation checks, tracking prevention, and other enabled engine features. These requests are governed by Microsoft's privacy statement.

The optional browser relay is off unless configured. It can connect to a local service at http://localhost:5200; when enabled, the configured service operator may process destination and connection information. The operator's logging and retention practices are not controlled by SKYNET, so review that operator's policy before using the relay. The relay is not a full-device VPN.

The browser can send Do Not Track (DNT) and Global Privacy Control (GPC) signals when enabled in settings. These preference signals do not guarantee that a website will honor them.

Sharing and collection

The publisher does not receive browsing history, bookmarks, cookies, assistant memory, or diagnostic logs through the browser. SKYNET does not include cloud synchronization, advertising, or analytics services. Information is sent to the websites and services you choose, and to platform services used by WebView2, as described above.

If you enable the optional relay, the service operator you configure may process connection information. The operator's practices are separate from the publisher's practices.

Permissions and control

Websites may request camera, microphone, or location access through standard web APIs. SKYNET asks before granting a website permission and stores your permission choice locally. You can revoke permissions in browser settings or Windows privacy settings.

You can clear available browsing data using browser controls. You can also remove remaining local data by deleting %LocalAppData%\SKYNET and %LocalAppData%\SCYxNETProfiles. Websites may retain information they collected during your visits.

Children and policy changes

SKYNET is a general-purpose browser and is not directed at children. The publisher does not knowingly collect personal information from children. This policy will be updated if the browser's data practices change.
